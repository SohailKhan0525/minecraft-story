# Java Edition

Initial target: **Minecraft Java Edition 26.3 + Fabric**

## Requirements

- JDK 25
- Gradle 9.6+ (or a generated Gradle wrapper)
- Minecraft Java Edition
- IntelliJ IDEA or VS Code

## First milestone

1. Launch Minecraft with the mod.
2. Confirm the mod loads.
3. Add the first story state.
4. Add the first NPC.
5. Add dialogue.
6. Add the first quest.
