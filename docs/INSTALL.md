# Minecraft Story — Chapter 1

## Install

### Java Edition

Download the Java .jar from the GitHub Release.

1. Install Minecraft Java Edition 26.3.
2. Install Fabric Loader 0.19.5 for Minecraft 26.3.
3. Put Fabric API 0.161.0+26.3 and the Minecraft Story .jar into .minecraft/mods.
4. Launch the Fabric 26.3 profile.
5. Create a new world.
6. Play.

The release JAR already contains the Chapter 1 voice audio. No separate audio download is needed.

### Bedrock Edition

Download the Bedrock .mcaddon from the GitHub Release.

1. Open the .mcaddon with Minecraft Bedrock.
2. Let Minecraft import it.
3. Create a new world.
4. Activate Minecraft Story — The Night the Sky Broke under Behavior Packs.
5. Activate Minecraft Story — Chapter 1 Voice Pack under Resource Packs.
6. Enter the world.
7. Keep game audio enabled.

The .mcaddon already contains the story logic and voice audio.

### Mobile

Android and iPhone/iPad use the Bedrock .mcaddon.

Open the downloaded .mcaddon and choose Minecraft when the device asks which app should open it.

### Consoles

Xbox, PlayStation and Switch use Bedrock. Their add-on installation path depends on the supported Bedrock/world/Realm workflow for that platform. The Java .jar is not a console file.

## Controls

Use normal Minecraft movement and interaction controls. Story choices appear in the story UI.

## Voices

Chapter 1 ships with spoken audio generated with open-source eSpeak/FFmpeg tooling. The release packages already contain the audio.

## Troubleshooting

If Java has no voice, make sure Minecraft Master/Players sound volume is enabled.

If Bedrock has no voice, make sure both the behavior pack and Chapter 1 Voice Pack resource pack are enabled.

Use a new world after installing a new release.
