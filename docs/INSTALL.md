# Minecraft Story — Install & Play

## Download

Open the latest stable GitHub Release.

- Java Edition: download the Minecraft Story .jar.
- Bedrock Edition: download the Minecraft Story .mcaddon.

Voice audio is already bundled. There is no separate audio package.

## Java Edition

Minecraft Java 26.3 with Fabric Loader 0.19.5 and Fabric API 0.161.0+26.3 is required.

Put the downloaded .jar and Fabric API in your .minecraft/mods folder, launch the Fabric 26.3 profile, create a new world, and start playing.

## Bedrock Edition

Open the downloaded .mcaddon with Minecraft Bedrock and let Minecraft import it.

Create a new world and enable the imported Minecraft Story behavior and resource packs.

The voice pack is included in the .mcaddon.

## Mobile

Android and iPhone/iPad use the same Bedrock .mcaddon.

Open the downloaded file with Minecraft.

## Consoles

Xbox, PlayStation and Switch use the Bedrock edition. Their installation path depends on the supported Bedrock/world/Realm workflow for that console.

## Voices

Chapter voices are generated by the GitHub Actions release pipeline from one canonical audio/voice_profiles.json table. A character keeps the same voice profile across chapters.

Players never need to install TTS tools.

## Controls

Use the normal Minecraft controls for your device. Story choices appear in the story interface.

## Updating

Use a fresh world when installing a new release so story world generation starts cleanly.
