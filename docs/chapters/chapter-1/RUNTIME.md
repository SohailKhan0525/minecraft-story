# Chapter 1 — 60-Minute Runtime

## Locked target

Normal first playthrough: **about 60 minutes**, with a safe range of **50–65 minutes**.

The chapter is deliberately not padded with grinding. The one-hour target is built from authored story, exploration, puzzles, short combat encounters, NPC conversations, reactive background chatter, and cinematic transitions.

## Dialogue and NPC density

Chapter 1 currently contains a dedicated authored dialogue system with **10 major scenes and 150+ authored lines**, including:

- Mara, Elias, Cael, Sera and the Hollow Knight.
- Funny recurring villagers Bram, Nessa, Pip, Toma, Old Renn and Lio.
- Optional village chatter that can trigger while the player explores.
- Character-to-character banter rather than only player-to-NPC exposition.
- Dry humor during dangerous scenes so the tone can breathe.
- Reactions to discoveries, danger, choices, and the player's evolving story state.
- Distinct voice direction for each major character.

The scene timing values are **story envelopes**, not a requirement to read every optional line on every playthrough. Optional chatter is deliberately replayable/ambient so a normal first run remains close to one hour.

## Pacing rules

- No repetitive resource grinding.
- No long empty walks.
- Main objectives remain readable through dialogue, landmarks, NPC behavior, and visual storytelling.
- Optional conversations enrich the chapter without blocking the critical path.
- Combat is short and story-driven.
- Major cinematics take control only briefly.
- Every 5–8 minutes introduces a new character beat, mystery, location, mechanic, or escalation.
- Branches change dialogue and future state rather than simply changing one sentence.
- Funny NPCs remain present as the story darkens, but humor never undercuts the major reveals.
## Separate quest gameplay budget

The **60-minute story/dialogue/cinematic envelope is separate from quest gameplay**. The quest layer is deliberately longer so exploration, puzzle solving, travel, and combat are not compressed into the dialogue runtime.

| Blue Fire | 11 min |
| Find Elias | 12 min |

Quest time is earned through multi-step objectives and real in-world traversal. Difficulty changes encounter pressure: Peaceful uses puzzle/exploration completion, Easy uses lighter combat, Normal uses the standard encounter count, and Hard adds additional enemies/waves.
