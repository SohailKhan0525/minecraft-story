# Chapter 1 — 60-Minute Runtime

## Target
Normal first playthrough: **50–65 minutes**.

The intended cinematic runtime is approximately 60 minutes. Exploration can shorten or extend the experience, but the main story should finish in one sitting.

## Runtime map

| Segment | Target |
|---|---:|
| Cold open — The Sky | 3 min |
| River awakening + Havenfall approach | 5 min |
| Havenfall + Mara + first NPC conversations | 8 min |
| Chapel + Blue Fire | 6 min |
| Elias + Silent Forest | 7 min |
| Observatory exploration | 10 min |
| Sera choice + dungeon escalation | 6 min |
| Hollow Knight | 3 min |
| Heart Chamber + boss | 8 min |
| Ending + post-credit | 4 min |
| **Total** | **60 min** |

## Pacing rules

- No quest should require repetitive resource grinding.
- Main objectives are always readable through dialogue, visual landmarks, or character behavior.
- Optional NPC conversations add flavor without blocking the main route.
- Combat encounters are short and story-driven.
- Cinematics should be frequent enough to create rhythm but never remove player control for long.
- Every 5–8 minutes should introduce a new character beat, mystery, location, mechanic, or escalation.
- The player should never spend ten minutes walking through empty terrain.
