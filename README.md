# Minecraft Story

**Chapter 1 — The Night the Sky Broke**

An original story-driven Minecraft adventure with spoken dialogue, quests, exploration, combat, choices, and a post-credit epilogue.

## Download and play

**Chapter 1 release:** ready-to-play Java and Bedrock downloads are published from verified GitHub Actions builds. Bedrock's `.mcworld` includes the story packs pre-enabled, a structured Chapter 1 route, interactive story objects, and an always-on `NEXT` guide.

Releases are generated by GitHub Actions from the latest published stable semantic version, with retry-safe version preparation, deterministic cross-chapter voice generation, and final self-contained packaging.

The public release contains ready-to-use builds:

- Minecraft Java Edition: one .jar with the Chapter 1 voice audio already inside.
- Minecraft Bedrock Edition: one ready-to-play `.mcworld` with the behavior/resource packs pre-enabled and voice audio included.
- Minecraft Bedrock Edition: one `.mcaddon` fallback plus separate `.mcpack` files.

No separate audio download is required.

On Bedrock, open the `.mcworld` and press Play. The world is structured as a guided server-style adventure: follow the lit route, talk to glowing named NPCs, use the Story Guide bell when lost, and follow the `NEXT` instruction on screen.

See docs/INSTALL.md for the simple player installation steps.

## Voices

Chapter voices are generated from one canonical audio/voice_profiles.json table with open-source eSpeak/FFmpeg tooling. The exact same canonical character profile is reused in Chapter 1 and Chapter 2, and release builds contain the generated audio.

## Platform model

Java Edition and Bedrock Edition are separate Minecraft runtimes, so each has its own release file. The story, dialogue, choices and audio design are shared between them.
